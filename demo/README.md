# ECA Connect

A static interactive prototype built with locally vendored Basecoat UI 1.0.2, HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` directly, or serve this directory with any static file server. There is no install or build step and no network connection is required.

## State

Demo interactions are saved in the browser so progress remains after a refresh. Use **Settings → Start again** to restore the sample information.

## Deploy to Vercel

Use `demo` as the Vercel project root. Choose no framework, leave the build command empty, and publish the directory as-is. No environment variables or functions are required.

## Boundaries

All information shown is fictional. Do not enter real personal, pastoral, or finance information.
