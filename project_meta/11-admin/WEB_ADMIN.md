# Church Web Admin

The web admin is the primary operational interface: dashboard, members, visitors, follow-ups, branches, ministries, groups, home cells, events, attendance, communications, automations, giving, projects, needs, content, AI tools, reports, audit logs, roles, feature configuration, and settings.

Navigation and data are permission and feature aware. Dashboards prioritize attention, ownership, and due work. Context should always show organization and, where relevant, branch or scope. Bulk actions require previews and safe cancellation.
