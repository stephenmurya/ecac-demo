# Demo Flows

## 1. Leadership overview

Open Overview → scan Sunday/visitor/giving summaries → choose an attention row → arrive at the relevant active screen.

## 2. Visitor follow-up

Open Visitors → select John Musa → inspect timeline → mark contacted or schedule follow-up → assign Airport Road Cell → optionally convert to member. State and metrics update locally.

## 3. Automation

Open Automations → select a card → inspect `Trigger → Audience → Personalization → Send` → toggle active/paused. No delivery occurs.

## 4. Giving

Switch to Member View → choose Giving → select a general fund or Projects → choose an active church project or approved ministry need → review progress → enter an amount or use the remaining balance → confirm → see a receipt reference.

## 5. Projects and needs

Open Projects & Needs → inspect Church Bus Project and Music items → choose an item → fund entirely, contribute money, supply a new item, or donate an owned item → confirm updated demo status/progress.

## 6. Ministry request and approval

Open Projects & Needs as Admin → submit a ministry need → view Pending Needs Approval → approve/reject/request changes. Approval publishes it to the member-facing need list.

## 7. AI follow-up

Open AI Assistant → create from “The Power of Consistency” sermon → edit → mark reviewed → send. Send stays disabled until review.

## Member directory

Open Members → search the church list → select a member → review contact details, branches, household links, membership stage, ministries, groups, home cell, interests, service, and message preferences.

## Follow-up assignment

Open Visitors or Follow-ups → schedule from today onward → choose a time → assign a church worker → save. Follow-ups can then be reassigned or completed with an outcome.

## Offline project contribution

Open Projects & Needs as an administrator → record offline gift → choose money or an item → choose the project or approved need → enter the contributor and receipt details → save.

## 8. Reset

Open Settings or utility menu → Reset Demo Data → confirm. Initial data, progress, visitors, needs, and AI draft are restored.
