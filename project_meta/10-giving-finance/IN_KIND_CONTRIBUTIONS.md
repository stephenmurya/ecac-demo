# In-kind Contributions

In-kind offers are not ₦0 financial donations and must not enter monetary totals as cash.

| Field | Example |
|---|---|
| Type | In-kind |
| Item | Stackable chairs |
| Quantity | 50 |
| Condition | New |
| Estimated value | Optional, clearly non-cash |
| Related need | Auditorium seating |

## Lifecycle

`Offered → Reviewing → Accepted/Declined → Awaiting delivery → Received → Completed`

Verification records quantity, condition, receiver, date, and discrepancy. Ownership transfer, valuation policy, receipts, unsuitable goods, partial delivery, and storage responsibility require policy.
