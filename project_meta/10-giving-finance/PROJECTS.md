# Projects

Projects are organization-approved fundraising initiatives with title, purpose, optional goal/deadline, funding progress, visibility settings, and linked fund/allocation.

Organizations decide whether members see the target, amount raised, percentage, deadline, donor names, or anonymous rollup. Progress is based on verified allocated transactions, not checkout attempts.

Example: Church Bus Project, ₦45,000,000 goal, ₦18,500,000 raised in the demo. Project status: `Draft → Approved → Public → Funded/Closed → Archived`.
