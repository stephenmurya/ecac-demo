# Ministry Needs

A ministry need is a reviewed request for one or more items or services. Each item can be approved independently.

```text
Ministry drafts request
→ submits request and items
→ church administration reviews
→ approve, reject, or request changes per item
→ approved items become public
→ members contribute money or offer an item
→ contribution verified and fulfilled
```

Fields include ministry, item, description, quantity, estimated cost, priority, optional image, reason, desired date, and public wording. Approval does not itself commit expenditure.
