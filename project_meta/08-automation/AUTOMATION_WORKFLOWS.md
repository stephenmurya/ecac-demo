# Automation Workflows

| Workflow | Trigger | Deterministic actions | Human checkpoint |
|---|---|---|---|
| Visitor follow-up | Visitor registered | Welcome, assignment, reminder | Worker chooses outcome |
| New member | Membership completed | Welcome, orientation, recommendations | Leader confirms placement |
| Event | Event published | Notify, remind, open attendance | Publisher approval as configured |
| Home cell | Weekly schedule | Insert correct details, remind | Leader reports attendance |
| Volunteer | Rota assignment | 24h and 2h reminders | Volunteer acknowledges |
| Post-service | Service completed | Prepare recap workflow | Content approval before send |
| Attendance care | Pattern detected | Create pastoral task | Human determines outreach |

Each workflow must state failure behavior, owner, stop conditions, communication budget, and audit coverage before production activation.
