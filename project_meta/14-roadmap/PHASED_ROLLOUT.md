# Phased Rollout

| Phase | Outcome | Exit evidence |
|---|---|---|
| 0: Discovery/demo | Leadership alignment and workflow validation | Decisions and pilot sponsor |
| 1: Foundations | Tenant model, identity, RBAC, audit, configuration | Isolation/security tests |
| 2: People/care | Members, visitors, follow-up, home cells | Pilot acceptance and privacy review |
| 3: Programs/comms | Events, attendance, push/email/SMS, automations | Delivery/cost/recovery tests |
| 4: Giving/needs | Funds, projects, needs, payments, reconciliation | Finance controls and provider sign-off |
| 5: AI assistance | Reviewed drafting and approved-source search | Evaluation, safety, cost controls |
| 6: Multi-tenant SaaS | Platform admin, provisioning, limits/billing | Operations/support readiness |

Phases are sequencing hypotheses, not delivery dates.
