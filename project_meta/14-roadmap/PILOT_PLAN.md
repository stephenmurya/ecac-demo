# Pilot Plan

## Proposed shape

One church, limited branches/teams, fictional or safely migrated data, named owners, and a short set of measurable workflows. Start with visitors/follow-up, attendance, home-cell reminders, and communications; introduce finance only after control design.

## Preparation

Map current processes, confirm data owners, choose pilot cohort, define consent/retention, train roles, test imports, prepare support and rollback, and baseline metrics.

## Measures

Follow-up assignment/completion time, visitor connection outcomes, reminder delivery, attendance finalization time, user adoption, errors, opt-outs, SMS spend, and staff-reported workload. Success does not mean maximizing messages.

Pilot duration, participating church/branches, provider choices, and acceptance thresholds remain open.
