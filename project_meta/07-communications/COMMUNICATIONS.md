# Communications

The communication domain coordinates push, SMS, and email across defined audiences. Push is generally the default low-incremental-cost channel; SMS is selective; email carries longer content.

## Campaign model

`Draft → Audience estimated → Cost/consent checked → Review/approval → Scheduled/queued → Sending → Completed with delivery outcomes`

Audience filters may include organization, branch, ministry, department, group, home cell, event attendance, member status, tags, and preferences. A campaign stores an audience snapshot and content version for audit.

Channel fallback, deduplication, quiet hours, rate limits, provider failure, opt-outs, and emergency exceptions require explicit policy.
