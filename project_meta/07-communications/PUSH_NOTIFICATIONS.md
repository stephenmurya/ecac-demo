# Push Notifications

Push should be the default for timely, short, app-connected communication because incremental delivery cost is low. It still requires consent, valid device tokens, sensible frequency, and deep-link safety.

Track queued, accepted by provider, delivered where supported, opened where supported, failed, and invalid token. Provider acceptance is not proof a person read the message.

Sensitive pastoral or finance content should not appear in lock-screen text by default.
