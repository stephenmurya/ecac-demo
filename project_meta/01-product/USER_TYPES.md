# User Types

| User type | Typical jobs | Sensitivity |
|---|---|---|
| Organization Owner | Governance, top-level settings, protected admin recovery | Highest |
| Church Administrator | Cross-module operations and configuration | High |
| Branch Administrator | Branch-limited members, events, attendance, reports | Medium/high |
| Pastoral/Follow-up Worker | Care assignments, outcomes, notes | Sensitive personal data |
| Communications Worker | Draft, approve, schedule, and send campaigns | Brand and consent risk |
| Finance Viewer/Officer/Approver | Summary, transactions, reconciliation, approvals | Highest financial data |
| Ministry Leader | Roster, schedules, need submissions | Scoped |
| Home-cell Leader | Cell membership, attendance, follow-up | Scoped personal data |
| Member | Profile, events, content, giving, group participation | Self-service |
| Visitor | Consent-based registration and communications | Limited profile |
| Platform Operator | Tenant support and platform operations | Separate control plane |

Users may hold multiple scoped role assignments. “Admin” is not a universal permission set.
