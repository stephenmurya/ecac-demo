# Feature Map

| Domain | Core capabilities | Primary surfaces |
|---|---|---|
| People | Members, visitors, tags, lifecycle, preferences | Web admin, member app |
| Care | Follow-ups, assignments, pastoral tasks, home cells | Web/mobile admin |
| Programs | Events, recurring programs, volunteer schedules | All |
| Attendance | QR/PIN concepts, registers, corrections, reports | Member and admin |
| Communications | Push, SMS, email, templates, segments | Web/mobile admin |
| Automation | Triggers, rules, actions, approvals, runs | Web admin |
| Giving | Funds, transactions, donor visibility, projects | Member app, web admin |
| Needs | Ministry requests, approval, funding, in-kind | Member app, web admin |
| Content | Announcements, resources, sermon follow-up | All |
| AI | Drafting, summarization, classification, knowledge search | Permissioned surfaces |
| Governance | Roles, scopes, feature config, audit, settings | Web/platform admin |

SESSIONS-informed concepts include members, campuses, events, attendance, announcements, community, resources, notifications, and scoped administration. New emphasis includes true multi-tenancy, custom-role composition, finance separation, workflow automation, giving needs, and dedicated web operations.
