# User Journeys

## Visitor care

`Registered → welcome queued/sent → worker assigned → reminder due → contact outcome → invitation/cell assignment → member conversion or nurture/closed`

The worker sees contact preferences, context, due date, and allowed actions. Pastoral notes require stricter visibility than ordinary CRM fields.

## Sunday operations

`Program prepared → audience reminded → attendance captured → register finalized → exceptions reviewed → follow-up draft prepared → human review → communication sent`

## Ministry need

`Leader drafts request → submits items → admin reviews each item → approve/reject/request changes → approved item published → member funds or offers item → finance/operations verifies → fulfilled`

## Giving

`Member selects fund → enters amount → provider checkout → server initializes transaction → provider webhook verifies → receipt and ledger status update`

Only the first two steps and a clearly simulated success are represented in the static demo.

## Role setup

`Owner chooses canonical permissions → selects scopes → previews effective access → assigns people → audit record created → periodic review`
