# Organization Configuration

Configuration describes how an available feature behaves.

| Area | Examples |
|---|---|
| Identity | Name, logo, timezone, locale, currency |
| Membership | Lifecycle labels, onboarding steps, required fields |
| Attendance | Check-in methods, correction window, finalization rules |
| Communications | Sender identity, channel defaults, quiet hours, approval thresholds |
| Giving | Funds, public progress, anonymity choices, receipts |
| AI | Enabled tasks, approved sources, review requirements, budgets |
| Home cells | Meeting cadence, location visibility, assignment rules |

Configuration is organization-owned, validated, versioned for sensitive changes, and audited where it affects access, communication, or finance.
