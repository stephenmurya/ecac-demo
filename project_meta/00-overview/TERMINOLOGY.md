# Terminology

| Term | Definition |
|---|---|
| Organization / church | Top-level tenant boundary |
| Branch / campus | Organization-owned location and operating scope |
| Member | Recognized person in the membership lifecycle |
| Visitor / first timer | Person recorded before membership conversion |
| Ministry / department | Functional service team such as Music or Welfare |
| Group | General organization-defined collection |
| Home cell | Small pastoral/community group with location and leader |
| Canonical permission | Platform-defined action key such as `visitors.manage` |
| Role | Organization-defined bundle of canonical permissions |
| Scope | Boundary within which a role assignment applies |
| Feature availability | Whether an organization can use a module |
| Feature configuration | How an enabled module behaves for an organization |
| Entitlement | Platform/commercial allowance governing access or limits |
| Automation | Deterministic trigger, rule, action, and review workflow |
| In-kind contribution | A non-cash item offered or supplied, tracked separately from money |
| Demo state | Browser-local simulated data with no production effect |
