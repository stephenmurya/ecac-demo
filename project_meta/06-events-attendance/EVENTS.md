# Events

Events have an owner, branch/location, schedule, audience, capacity/registration settings, publishing state, communications, attendance occurrence, and optional follow-up.

## Lifecycle

`Draft → Review (optional) → Published → In progress → Completed → Archived/Cancelled`

Publishing can trigger audience notification and scheduled reminders. Editing date, venue, or cancellation after notification requires an impact preview. Public/member visibility and administrative edit permission are separate.
