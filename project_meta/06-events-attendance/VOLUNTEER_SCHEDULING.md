# Volunteer Scheduling

Future volunteer scheduling links program roles, qualified people, availability, acknowledgements, reminders, and substitution.

```text
Coordinator creates rota
→ volunteer scheduled
→ 24-hour reminder
→ acknowledgement or decline
→ replacement/escalation if needed
→ 2-hour reminder
→ service outcome recorded
```

The system should prevent obvious conflicts and respect quiet hours. Qualification, safeguarding, recurring availability, swap approval, and no-show policies remain open. This module is documented but not interactive in the demo.
