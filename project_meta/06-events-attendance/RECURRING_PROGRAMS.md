# Recurring Programs

Recurring programs represent stable church rhythms such as Sunday services, Tuesday Bible study, and weekly home cells. A template generates dated occurrences; each occurrence can be changed without rewriting the series.

```text
Program template + recurrence rule
→ occurrence generated
→ reminders scheduled
→ local exceptions applied
→ attendance opened/finalized
→ follow-up eligible
```

Timezone, daylight-saving behavior for international tenants, exception dates, branch-specific variants, and “edit one versus all future” semantics must be explicit.
