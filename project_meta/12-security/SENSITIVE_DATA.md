# Sensitive Data

| Class | Examples | Additional controls |
|---|---|---|
| Identity/contact | Phone, email, address | Scoped access, masking/export control |
| Pastoral | Care notes, prayer/welfare context | Restricted purpose roles, access logging |
| Attendance | Individual participation history | Limited use, no shaming automation |
| Finance | Transactions, donor identity, refunds | Independent permissions, immutable audit |
| Credentials/secrets | Provider keys, tokens | Secret manager, never client or logs |
| Children/minors | Profiles, guardians, attendance | Safeguarding policy and tighter defaults |
| AI inputs | Transcripts, prompts, retrieved sources | Provider controls, minimization, retention policy |

The static demo contains fictional data only and must never receive real sensitive information.
