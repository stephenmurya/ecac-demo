# Pastoral Workflows

Pastoral work begins with a signal and creates a human-owned task, not an automatic conclusion.

```text
attendance or care signal detected
→ eligibility and sensitivity checked
→ pastoral task created
→ authorized person reviews context
→ human chooses outreach
→ outcome recorded with minimum necessary detail
```

Examples include absence patterns, bereavement, illness, new-member orientation, welfare requests, and requested prayer follow-up. Automated copy must never shame a person or state surveillance-like attendance facts. Restricted notes need purpose limitation, tighter permissions, access logging, retention rules, and safe export behavior.
